这次改版把整个站点的视觉推翻重做了一遍,记录几个关键决策。

## 为什么明亮为默认

原来的暗色玻璃拟态很好看,但内容型站点(博客)的可读性优先级更高。明亮白底 + 细边框 + 柔和投影,阅读更省力,和「简洁明亮」的定位一致。深色主题保留为选项,而且暗色下有专属彩蛋——萤火粒子。

## 琥珀色

品牌色从玫红换成琥珀 `#f59e0b`。暖、轻快,与「照亮 / 旅人」的文案气质契合。

## 导航的取舍

顶栏保留 6 项主导航(主页 / 博客 / 图集 / 音乐 / 项目 / 设置),「关于」收进底部胶囊区——胶囊同时承载了 logo 回主页钮、访客统计和 GitHub 链接,页脚一个组件办完所有「站点级」的事。

## 动效总开关

设置页新增总闸:关掉之后滚动、轮换、屏保自动进入、Ken Burns、过渡动画全部静止。系统开了「减少动态效果」的用户会被自动照顾到。

| 决策 | 结果 |
| --- | --- |
| 默认主题 | 明亮 |
| 品牌色 | 琥珀 |
| 玻璃拟态 | 仅导航与悬浮层 |
| 装饰粒子 | 仅暗色主题 |
